# Session handoffs
Keep at most 12 short lines (more only when technically necessary): task, goal, baseline branch and status, touched files, architecture decisions, test evidence, blockers, unresolved risks, next exact action, required approval. Avoid raw transcripts and private info. Resume by checking `git status`, latest commit and changed files rather than rereading entire history. For complex long projects use a concise decision log and current-state file; update only on meaningful change. Do not make stale handoff override working tree.

Template in `assets/HANDOFF.template.md`.
