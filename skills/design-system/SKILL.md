# SeuMadruga Design System

**Por Rômulo Bezerra** | SeuMadruga Ecosystem 2.0

## Quando usar
frontend, interface, UX, UI, design system, componentização, responsividade, microinterações.

## Procedimento
1. Audite marca, tokens e interfaces existentes.
2. Defina hierarquia, jornada, componentes e estados.
3. Implemente UX responsiva, foco, teclado e acessibilidade.
4. Use microinterações e visualização avançada somente quando melhorarem a experiência.
5. Valide contraste, overflow e legibilidade por inspeção real quando possível.
