# Checklist: SeuMadruga Design System

**Autor: Rômulo Bezerra**

- [ ] Escopo e critérios de aceite definidos
- [ ] Instruções originais e autorizações respeitadas
- [ ] Audite marca, tokens e interfaces existentes.
- [ ] Defina hierarquia, jornada, componentes e estados.
- [ ] Implemente UX responsiva, foco, teclado e acessibilidade.
- [ ] Use microinterações e visualização avançada somente quando melhorarem a experiência.
- [ ] Valide contraste, overflow e legibilidade por inspeção real quando possível.
- [ ] Testes executados distinguidos dos não executados
- [ ] Limitações e riscos registrados
