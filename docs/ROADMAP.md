# Roadmap and evidence policy
**0.1**: static skill + offline validator + documentation. **0.2**: fixture-backed correctness benchmarks, Claude/Codex compatibility matrix by exact release. **0.3**: optional local telemetry importer without exfiltration, anonymization and cost estimator where provider price data are verifiable. **1.0**: reproducible published benchmarks, documented safety audit, governance and maintenance procedures.

Do not claim any milestone completed without corresponding tests and release artifacts. Avoid adding always-running agent processes: monitoring itself can consume tokens.

- v0.1.5: Added opt-in, cross-platform environment efficiency and Windows profile protection guidance; no automatic cleanup or global configuration changes.
