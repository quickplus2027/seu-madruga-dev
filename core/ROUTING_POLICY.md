# Política do SeuMadruga CORE

1. Preserve e respeite a skill original `skills/seu-madruga-dev/SKILL.md`.
2. Selecione apenas especialidades úteis à tarefa, usando `core/skill-registry.json`.
3. O roteador é heurístico e não instala/ativa skills automaticamente.
4. Inclua segurança e QA quando o risco justificar.
5. Respeite permissões, instruções superiores e aprovações do projeto.
6. Planeje, execute, valide e reporte evidências reais.
7. Não invente hooks, CI, telemetria ou automação não instalados.
